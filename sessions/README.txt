Saved sessions
==============

Video Redline keeps the sessions you save in this folder.

How it works
- Open video-redline.html in Chrome, Edge or another Chromium browser.
- Open a video, then choose File, Save session. The first time, the page asks you to
  pick a folder: pick this "sessions" folder. The browser remembers it.
- After that, File lists every saved session. Click one to open it. The small buttons
  at the side of a row rename it, make a copy of it, or delete it.

You can copy, back up or share the .json files in this folder. A session holds your
markers, not the video, so open the same video before you open its session.

Other browsers (Firefox, Safari) cannot use a folder this way. There, use
File, Download session file and File, Load session from file.
